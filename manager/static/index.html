❓ How to join a server

  1. Find the server above and click its join address to copy it.
  2. Open the game → multiplayer → join by IP / address → paste.
  3. If it loads long on first join, that's normal (world sync) — Palworld first joins can take several minutes.

🕹 About this project

GameHub is an open-source (MIT) panel: a Python FastAPI backend driving game servers as Docker containers, with a no-build web UI. One /admin login controls everything — live console + RCON, player kick/ban, config editors, mods, backups, updates with progress, metrics — while this homepage and per-server /share pages stay public for players.

Game templates make new titles easy: Palworld, Minecraft Java, Valheim and Project Zomboid ship built-in, and any Docker image can be added as Generic. Palworld server mods note: UE4SS script mods are Windows-server-only; Linux servers run .pak/config mods.
