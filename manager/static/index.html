❓ How to join a server

  1. Find the server above and click its join address to copy it.
  2. Open the game → multiplayer → join by IP / address → paste.
  3. First joins can load long (world sync) — Palworld first joins take several minutes. That's normal.

⚙ How it works

🖥1. Host
One Linux box runs everything (this page + the games).
📦2. Docker
Each game runs isolated in its own container.
🎛3. Manager
GameHub starts, monitors, updates and backs them up.
🌐4. Tunnel
playit exposes game ports — no router setup, works behind CGNAT.

Admins get a private /admin panel: live console + RCON, player kick/ban, config & settings editors, mods, backups, one-click updates with progress, and metrics. Players only ever see this page and per-server /share pages — no login needed.

💾 Open source — run your own

GameHub is free and open-source (MIT). Put it on any Ubuntu server with Docker and host your own games the same way: one command installs the manager, and the playit agent gets you past CGNAT without touching your router. Fork it, add game templates, self-host forever — no accounts, no fees, your data stays on your box.

git clone https://github.com/ikazreal21/gamehub.git /opt/gamehub
cd /opt/gamehub && chmod +x setup-server.sh
sudo ./setup-server.sh --admin-pass 'strong-password' --with-playit --yes

Stack: Python FastAPI + vanilla JS, Docker Compose deploy. Templates for Palworld, Minecraft Java, Valheim, Project Zomboid + Generic/Custom — new games are one block in games/templates.py.
